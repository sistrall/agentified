# GitHub Copilot in the editor. Not included in the `editor` profile: Copilot
# sends your code to GitHub for completions, which is a decision to make on
# purpose rather than inherit.
#
# Note the allowlist reference is written in terms of URLs with paths. We can
# only express hostnames (see 0003-filter-by-name-not-by-decrypting), so entries
# like https://api.github.com/copilot_internal/* become the whole host — which
# `base` already permits.

# --- completions and chat -------------------------------------------------
# The reference lists *.githubcopilot.com plus per-plan subdomains
# (individual/business/enterprise); the leading dot covers all of them.
#
# This also happens to cover api.githubcopilot.com, which is where GitHub's
# remote MCP server lives. If the MCP server is all you want, use the narrower
# `github-mcp` profile instead of this one — it grants that endpoint without
# opting into sending your code to GitHub for completions.
.githubcopilot.com

copilot-proxy.githubusercontent.com
origin-tracker.githubusercontent.com
