# VS Code and Zed both install a server component into the container *after* it
# starts, and extensions and language servers download from these hosts. A
# firewall that comes up at postStart will otherwise strangle the editor's own
# bootstrap, and the failure looks like "the container is broken", not "a
# domain is missing".
